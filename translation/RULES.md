# 질 올 인피니트 번역 규칙

## 입력·출력
- 입력: `translation/jobs/NNN.jsonl` — 한 줄에 `{"id", "file", "entry", "jp"}`. 같은 파일·항목 순서라 앞뒤 줄이 대화 문맥이다.
- 출력: `translation/out/NNN.jsonl` — 한 줄에 `{"id": 같은 id, "ko": 번역}`. 모든 id 를 빠짐없이.
- 검사: `python tools/check_job.py NNN` 오류 0건이 될 때까지 고친다.

## 표기
- `\n` 은 줄바꿈. 번역도 원문 줄 수 **이하**로, 각 줄 폭은 원문 최대 줄 폭 이하(+1)로 맞춘다. 한글 1자=1칸, 반각 공백·영숫자 0.5칸.
- 태그는 원문과 같은 **개수·순서**로 그대로 둔다: `<V28>`(주인공 이름), `<V15>` `<V16>` `<V17>` `<V1A>` `<V1B>` 등(지명·수치 변수), `<Ch>…<Co>` / `<Ce>…<Cf>`(색), `<Xnn>`(제어).
  변수 뒤 조사는 받침 유무를 모르므로 `(이)라는`, `을(를)` 대신 가능한 한 조사 없이 쓰거나 `<V28> 님` 처럼 자연스럽게 피한다.
- 원문 줄 앞의 전각 공백(　) 가운데 맞춤은 신경 쓰지 말고 **줄 앞 공백 없이** 번역한다(빌드가 자동 가운데 맞춤).
- 띄어쓰기는 반각 공백(` `). 문장부호: `…` `！` `？`(또는 반각 !?), `、`→`,` 대신 한국어 쉼표 `,`, `。`→`.`.
- 한글은 KS X 1001 완성형 2,350자만(검사기가 경고). 일본어 가나·한자를 남기지 않는다. 한자 병기 금지.
- `%s` `%u` `%d` 같은 서식 문자열은 그대로, 순서도 유지.

## 번역 품질
- **기계번역 금지.** 문맥을 보고 자연스러운 한국어로 직접 쓴다. 뜻을 빼지 않되 폭이 모자라면 조사·중복을 줄여 다듬는다.
- 인물별 말투 유지: 기사·귀족은 격식체(~하오/~합니다), 노인은 ~하네/~구먼, 여자아이·요정은 귀엽게, 악당은 거칠게. 일본어의 일부러 틀린 말투는 표준 맞춤법으로.
- 고유명사는 `translation/glossary.tsv` 를 따른다. 없는 이름은 국립국어원 외래어 표기법에 가깝게 음역하고 결과 파일 끝 `{"id": -1, "ko": "새용어: 원문=번역; ..."}` 한 줄로 알린다.
- 게임 용어: ギア=기어(화폐), ソウル=소울, スキル=스킬, 冒険者=모험자, 宿屋=여관, 酒場=주점, ギルド=길드, 無限のソウル=무한의 소울.
- 개발용 문자열(だみぃ, 未使用, 파일 경로 `\DATA\...`, 영어 디버그)은 뜻만 간단히 옮기거나 그대로 둔다(일본어만 없으면 됨).
