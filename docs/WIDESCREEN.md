# 16:9 와이드 패치 (PCSX2 전용)

웹(PCSX2 공식 패치 모음 포함)에 이 게임(SLPM-65892)의 와이드 패치가 없어 직접 만들었습니다.

| 파일 | 대상 | 게임 CRC |
|---|---|---|
| `SLPM-65892_E206B1A4.pnach` | 한글판 ISO (이 패치를 적용한 ISO) | `E206B1A4` |
| `SLPM-65892_FC6BAAF0.pnach` | 일본 원본 ISO | `FC6BAAF0` |

## 적용 방법 (PCSX2 1.7 / 2.x)
1. 릴리즈에서 쓰는 ISO에 맞는 `.pnach` 를 받습니다(한글판이면 `SLPM-65892_E206B1A4.pnach`). **파일 이름을 바꾸지 마세요.** PCSX2 가 이름의 CRC 로 파일을 찾습니다.
2. PCSX2 메뉴 **도구 → 데이터 디렉터리 열기**로 연 폴더 안의 `patches` 폴더에 넣습니다. 폴더가 없으면 만드세요. 휴대용(portable) 설치는 `pcsx2-qt.exe` 옆의 `patches` 폴더입니다.
3. 게임 목록에서 질 올 인피니트를 **우클릭 → 속성 → 패치** 탭에서 **Widescreen 16:9** 에 체크합니다.
4. 게임을 실행합니다. 화면 왼쪽 위에 "1개의 게임 패치가 활성화되었습니다"가 뜨면 적용된 것입니다. 화면 비율은 패치가 자동으로 16:9 로 바꿉니다.

끄려면 3번의 체크를 해제합니다. 화면 비율이 16:9 로 남아 있으면 설정 → 그래픽 → 화면 비율을 **자동 4:3/3:2** 로 되돌리세요.

## 원리와 한계
- 게임의 3D 투영 행렬 함수(0x13D948)가 행렬을 채우기(0x13DE50) 직전에, 세로 배율에 4/3 을 곱하는 짧은 코드를 빈 메모리(0xFFF80)에 넣습니다. 그래서 16:9 화면에서 인물·배경이 늘어나지 않고 원래 비율로 보입니다.
- 방식은 **Vert-**(가로 시야는 원본 그대로, 위아래가 조금 잘림)입니다. 가로 시야를 넓히는 Hor+ 방식도 시험했습니다. 그런데 실내 장면은 카메라가 방 크기에 맞춰 화면 위치를 계산하므로, 방이 왼쪽으로 쏠리고 오른쪽이 비는 문제가 생겨 쓰지 않았습니다.
- 메뉴·대화창·타이틀 같은 2D 화면은 가로로 늘어나 보입니다.
- 게임 파일(ISO)은 바꾸지 않습니다. 에뮬레이터 메모리에서만 적용됩니다.
- 실기(PS2 본체)용이 아닙니다.
